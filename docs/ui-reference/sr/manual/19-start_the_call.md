## Navigation and behaviour
- Tapping হ্যাঁ starts the call: the camera opens for the outlet photo (screenshot 20).
- না does not start the call (behaviour not stated).
- If the SR taps এগিয়ে যান (or tries to enter quantities) before starting the call, the pop-up "Please start the call to continue." appears; ওকে closes it.
- Sale History opens the sale data page (screenshot 23); আজকের টার্গেট opens the target pop-up (screenshot 21).

- "Sale History" is English in the image; "Please start the call to continue." is also English, while the question and buttons are Bangla.
- The manual describes the pop-up as appearing "if you try to sell first"; the image shows it with the cart still ০.০০ and the proceed button visible behind it, so it may be triggered by এগিয়ে যান (not confirmed).
