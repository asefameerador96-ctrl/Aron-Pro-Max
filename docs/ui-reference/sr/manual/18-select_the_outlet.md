## Data and figures shown
- Each outlet label has the pattern: Name (outlet code - phone - cluster name). The code (3700xxx) is 7 digits. Some phone fields are 11 digits starting 01, some are 10 digits without the leading 0, and some are "123" (placeholder phone).
- Cluster names seen: "111 No Road", "108 No Road", "109 No Road", "Lakepar", "Pink City", "Pink City Road", "Samsul Alamin Vobon".
- The list is sorted by descending outlet code (3700936 down to 3700612).
- The alphabet bar offers only letters that start an outlet name on the route (A B F G H I J K L M N O R S V Y), plus All.
- The yellow dot at each row looks like a status marker (colour code; meaning not in the manual).

## Colours and style
- Header red-to-deep-purple gradient; page light grey; drop-down field white with large rounded corners.
- Alphabet bar dark grey (about #4F4F4F) with white letters; the selected chip uses the red-to-purple gradient.
- Open list: very pale lavender-white background, black text, Roboto-like Latin font; Bangla text in the app font.
- Yellow-orange (about #F5B800) round dots in front of each outlet.
- Standard Samsung-style three-key navigation bar at the bottom.

## Navigation and behaviour
- Tap the drop-down to open the list of the route's outlets and pick one; or tap a letter in the alphabet bar to filter the list by first letter.
- After an outlet is chosen the page changes to the call screen (screenshot 19).
- Back arrow returns to the home page.

## Differences between the image and the manual text
- The manual says the right side shows "name, code, phone and cluster". The image shows exactly this as one text string "Name (code-phone-cluster)", with no separate columns or labels.
- The manual does not mention the coloured dot in front of each outlet, nor the small brown logo on one row (Ajij Tea Store).
- The manual does not say the alphabet bar has only letters that exist on the route.
