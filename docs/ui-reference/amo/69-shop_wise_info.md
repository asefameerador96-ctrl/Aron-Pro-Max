## Data and figures shown
- Left: three outlets of the route "Savar Bazar(Sat, Mon, Wed)". The text in brackets after the outlet name is shop code - phone - area (e.g. 1618408-1942222558-Madrasa Road), so the phone number repeats in the name and in যোগাযোগ.
- Sub-Channel is the Astha tier (Diamond, Gold). Wing/Division/Territory/Zone is the outlet's place in the sales hierarchy (Dhaka / Savar / Savar / Savar Metro for all four outlets).
- Right: STD (volume) target table for Zafor Store, 2025 Q-4, no month highlighted. Columns: target, achievement, remaining, percent. Maxim 860 target, 10,000 achieved, remaining 0 (remaining clamped at 0 when achievement exceeds target), 10,000 / 860 = 1,162.79 %. Black Diamond 10,270 target, 1,000 achieved, remaining 9,270, 1,000 / 10,270 = 9.74 %. Abul Bidi Style and Marise have target 0, achievement 1,250 and 8,000, remaining 0, 0.00 %.
- Digits: the table numbers and percents are in Bangla digits (০১২৩৪৫৬৭৮৯) with Latin comma thousand separators (1,000 style grouping) and a Latin dot as decimal mark. Year, quarter, months, phone numbers and shop codes are Latin digits.

## Navigation and behaviour
- Per the manual: tap "দোকান ভিত্তিক তথ্য" (second tab of the Astha screen), choose an outlet, then choose year, quarter and month(s). The STD target table then shows brand-wise target, achievement, remaining and %.
- Left list shows the Astha outlets of the chosen route (route chosen in the drop-down); tapping an outlet card opens the right-hand detail (inferred from the manual wording "choose an outlet").
- The manual says "Select one month or all three months" (from the Route info sections): month buttons toggle; tapping the "মেমো টার্গেট" tab switches to the memo target table (screenshot 70).
- "রুটের তথ্য" tab returns to the route-wise view (screenshots 67 and 68).
