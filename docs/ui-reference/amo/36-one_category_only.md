- Tapping a category label (Cigarette, Bidi, Lighter, Match) in the summary card filters the card and the table to that category only (per the manual). The image shows the result for Bidi. The card then shows only that category's bar, and the table only that category's brands.
- The manual does not say how to clear the filter (probably tap again or press back); the image shows no filter chip or clear button. The back arrow at top-left is the only visible control.
