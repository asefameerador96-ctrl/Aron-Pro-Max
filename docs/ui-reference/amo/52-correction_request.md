## Navigation and behaviour
- Per the manual: left list shows outlets whose information an SR changed. Tap one to open it. Correct anything wrong (shop name, owner name, mobile, Sub-Channel, Geo Classification), tap সংরক্ষণ and confirm with হ্যাঁ. Then "Data Updated Successfully" (screenshot 53). বাতিল cancels.
- Route drop-down looks active; cluster drop-down looks greyed.
