## Navigation and behaviour
Per the manual: after tapping সংরক্ষণ the data is saved and the dialog "ডেটা সফলভাবে সংরক্ষিত হয়েছে" appears; tap ওকে to dismiss. The image shows that after the dialog the app is on the Control Call activity screen with the route still selected and the outlet field cleared (the alphabet bar is shown, tiles behind). The dialog has one button only.

## Differences between the image and the manual text
- The manual says the left screen is "the completed assessment"; the image shows a partly filled form (OOS: three brands ticked, POSM: না) scrolled to the lower half.
- The manual does not say that after OK the user lands on the Control Call activity screen with the outlet selection reset; the image shows this (the title behind the dialog is "কন্ট্রোল কল অ্যাক্টিভিটি").
- The manual does not mention the green check icon in the dialog or that the message ends with a full stop "।".
