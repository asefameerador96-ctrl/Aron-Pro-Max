## Data and figures shown
- Memo target counts memos (invoices/calls with a sale), not sticks: target 28 memos, achievement 5, remaining 23 (28 - 5), % = 5 / 28 = 17.86%. The numbers are consistent.
- Only one row ("All Brand") is shown; memo target is not split by brand.
- Figures are in Bangla digits.

## Colours and style
- Same as screen 67: deep purple top bar and selected-tab pill, light grey page (about #F3F3F3), white-bordered table rows, lavender header with bold deep-purple text, white-fill drop-downs with purple outline when focused, light grey month chips.
- No progress bar, no icons beyond the back arrow, no packshots.

## Navigation and behaviour
- Tap "মেমো টার্গেট" to switch from the STD (volume) target table to the memo-count target table; the route, year, quarter and month selections stay.
- Table is read-only.
- Back arrow returns to the Dashboard (or the previous screen).
