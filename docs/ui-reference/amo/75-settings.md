3. Below the tiles: empty page (nothing else).
4. Bottom: black system gesture bar with a short grey pill.
5. Right screen only: a white popup menu (rounded, strong shadow) hangs from the top-left, starting just under the top bar and covering the language tile. It has two rows: (a) black flag icon + "en" in purple, (b) black flag icon + "বাংলা" in purple. No row is highlighted or ticked in the image.

## Navigation and behaviour
- Tapping the language tile opens the drop-down with "en" and "বাংলা"; choose en for English or বাংলা for Bangla (per manual). The app labels switch language.
- PDA টু সাপোর্ট sends the device data (sync) file to support when support asks for it; on success the success dialog of screenshot 76 appears.
- লগ আউট logs the AMO out (no confirmation dialog is shown in the image).
- Back arrow returns to the dashboard.
