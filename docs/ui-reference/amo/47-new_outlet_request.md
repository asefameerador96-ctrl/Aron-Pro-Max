- Left list: tap a request card to open it (per manual) and go to the form on the right.
- Right form: the AMO checks the details and chooses the Sub-Channel and Geo Classification (the two empty drop-downs). Route and cluster are pre-filled from the SR's request (and look editable drop-downs).
- The Save/Cancel actions and the GEO photo capture appear in the next screenshot (48).
- Back arrow returns to the previous screen (Outlet menu for the list; the list for the form).
