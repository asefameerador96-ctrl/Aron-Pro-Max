## Data and figures shown
- Summary card: zone-level achievement/target per category (Cigarette, Bidi, Lighter, Match), same structure as screen 34 but with the Bidi row added, showing the category rows that have a target in this zone.
- Table: one row per brand/item. টার্গেট = target for the period, অর্জন = achievement, বাকি = remaining = max(target minus achievement, 0) (over-achieved rows show ০), % = achievement / target with two decimals (can exceed 100%, e.g. ২০২.৪৯%, ২৪৩.২৬%).
- On the Till Date tab the targets are the till-date shares (smaller), achievements are unchanged, so % is higher and বাকি is lower than on Monthly.
- Table percentages use two decimals; the summary percentages are whole numbers.
- All figures are in Bangla digits.
- Table covers all categories together (cigarette brands and bidi brands in one list, sorted apparently by category, cigarettes first, then bidi); this is not filtered by category on this screen (screen 36 shows the filtered view).

## Colours and style
- Top bar: deep purple (about #4A1A9A), white title and back arrow.
- Page background: very light lavender-white.
- Tab toggle: green outline, selected segment green fill (about #50BE80).
- Summary card: white, large radius, soft shadow. Bars: grey track with red / amber / green fill (same bands as screen 34: red under about 40, amber mid, green from about 80); percentage text coloured the same.
- Table header: light lavender fill, bold purple text (Item in Latin bold, others Bangla bold), table body white with thin grey grid lines, dark text.
- No packshot images, no icons in the table.

## Navigation and behaviour
- Opened from "বিস্তারিত →" on a zone or route card of Team Performance (screen 34). The title shows the zone name (here "Agrabad").
- Back arrow returns to Team Performance.
- Tabs switch between Monthly and Till Date; the bars and table both refresh.
- Table scrolls vertically (the whole page scrolls, header scrolls away; no sticky header is visible).
- Tapping a category label on the summary card shows only that category (screen 36).

## Differences between the image and the manual text
- The tab labels here are English "Monthly Target" and "Till Date Target"; on screen 34 the first tab is Bangla "মান্থলি লক্ষ্য" and the manual calls it মাসিক লক্ষ্য.
- The manual's Item column header and "%" are as shown; the manual does not mention that "Item" is English while the other headers are Bangla.
- The summary card includes a বিড়ি (Bidi) row; manual mentions "(and Bidi)" only in passing.
- Percent in the table has two decimals; the manual does not say.
- The manual does not mention that Item names are Latin and wrap onto 2 to 3 lines, nor that numbers wrap inside narrow cells.
