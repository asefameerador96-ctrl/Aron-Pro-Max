## Data and figures shown
- Target = the quarter's STD (standard, i.e. volume) target per brand for the chosen route; achievement = what has been sold; remaining = target minus achievement, never below 0 (Maxim shows 0 though achievement exceeds target); % = achievement / target.
- Checks: 33,020 / 12,480 = 264.58% (matches). 2,000 / 218,010 = 0.92% (matches). 7,500 / -20 = -37,500% (matches, with a negative target in the data). 6,250 / 0 shown as 0.00% (division by zero shown as 0.00%). 0 / 16,360 = 0.00%. Supreme remaining 16,360 = target.
- Avon: 5,000 / 8,180 would be 61.12%, and its remaining would be 3,180, but the screen shows remaining 0 and a % that reads like 119.62%; so either the digits are misread or the data is inconsistent (possible mix of months). Flagged as a question.
- Remaining is 0 for rows 1, 3, 4 and 5, which suggests remaining = max(target - achievement, 0), and 0 where the target is 0 or negative; row 5 conflicts unless target is less than 5,000.
- Example values are test or live data for Savar Bazar route, Q4 2025.

## Navigation and behaviour
- Top tabs: "রুটের তথ্য" shows route-level targets for the chosen route; "দোকান ভিত্তিক তথ্য" shows shop-wise info (not shown here).
- Choose the route first (drop-down), then Year, then Quarter (Quarter is disabled until a year is chosen). With no data the screen says "তথ্য পাওয়া যায়নি".
- After year and quarter, the month chips for that quarter appear (Oct, Nov, Dec for Q-4). Manual: select one month or all three months; no chip is highlighted in the image, so the default appears to be all three months (to confirm).
- Sub-tabs "এসটিডি টার্গেট" (this image) and "মেমো টার্গেট" (screen 68) switch the target type; the table scrolls vertically.
