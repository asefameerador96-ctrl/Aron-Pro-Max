## Data and figures shown
- Outlet codes 2631115 and 1618411, each followed in the label by a second long number (1744905700 / 1723412771; looks like a timestamp-style id; meaning not given in the manual).
- The alphabet bar lists the first letters of outlet names on the selected route (different between the two screens). The manual does not explain these further.

## Colours and style
- Top bar deep purple (indigo); page light pink/lavender.
- Fields: white, rounded, 2 px purple border.
- Alphabet bar: dark grey rounded panel; selected chip "All" green gradient with white text; other letters white text on dark grey.
- Update button: green gradient (olive-green to green), white text, rounded.
- Dialog: white, big rounded corners, yellow warning triangle, blue message text, green and red buttons.
- Scrim: dark translucent on the right screen.
- No packshots.

## Navigation and behaviour
Per the manual: stand at the outlet; select the route, then the outlet (the alphabet bar filters the outlet list by first letter; "All" shows all); tap আপডেট বেস; the confirmation dialog asks whether to update the retailer's location; tap আপডেট to continue (the camera then opens to photograph the outlet, then the map confirmation, screenshot 64); tap বাতিল to cancel.

## Differences between the image and the manual text
- The manual's title is "Select the outlet"; the screen title in the image is still বেস রিক্যালিব্রেশন.
- Alphabet bar is not described in the manual text for this screenshot (only "alphabet bar"); the image shows specific letters, and the letter set differs between routes. Lower-case "m" and "s" appear as separate chips on the left.
- The right screen shows a different route (Savar BazarDaily) and outlet (Babu Store) than the left, so the two halves are not a continuous flow of the same selection.
- The manual says Update/Cancel buttons are আপডেট / বাতিল; image confirms the order (Update green left, Cancel red right).
