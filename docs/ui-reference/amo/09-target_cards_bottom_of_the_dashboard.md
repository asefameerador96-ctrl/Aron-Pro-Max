## Data and figures shown
- Each blue card shows "completed / total": আজকের টার্গেট = target completed today / today's total target; টোটাল কল টার্গেট = calls completed this month / this month's total call target; কন্ট্রোল কল টার্গেট = control calls completed this month / monthly control call target; জয়েন্ট কল টার্গেট = joint calls this month / monthly joint call target (per the manual).
- Example values: all four are 0/0 (Latin digits, no separators, no % or unit).
- Outlet tile badge: 8 shown in a Bangla digit (৮); the manual does not explain it (likely count of pending outlet requests; see open questions).
- Date in the top bar 2025-12-01 is Latin digits, ISO format.
