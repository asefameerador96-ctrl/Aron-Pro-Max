## Data and figures shown
- Report period "October 1, 2026 - October 25, 2026": default is the 1st of this month to today (per manual).
- Each row is a route of the area; each column is a product category (সিগারেট, লাইটার, and further categories off screen to the right, e.g. match, bidi per the manual's "swipe left to see all categories"). Figures are STD (volume in base units: cigarette sticks, lighter pieces) sold in the period. The bottom row totals each column.
- All figures are Bangla digits with Latin-style thousand commas; the date and the route names are Latin. No percent or unit symbol shown.
- Cigarette total about 1.55 million sticks; lighter total 5,844.

## Navigation and behaviour
- Per the manual: tap Report on the dashboard, then the report you need (LEFT tiles). Tap "এসটিডি মেমো রিপোর্ট" to open the table.
- Change the dates at the top (tap the date field; a date-range picker is implied). Default range is this month to today.
- Swipe left to see all categories (the table scrolls horizontally).
- Tapping "এখন পর্যন্ত বিক্রয় সারসংক্ষেপ" opens the report in screenshot 72.
