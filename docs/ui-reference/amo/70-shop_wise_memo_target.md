## Data and figures shown
- Memo target for Zafor Store, 2025 Q-4, months Nov and Dec selected: target 11 memos, achievement 1 memo, remaining 10, 1 / 11 = 9.09 %. Counts are memo counts, not volume.
- Only one row, "All Brand" (the memo target is not split by brand).
- Table figures are in Bangla digits; year, quarter, month names, phone and shop code are Latin.

## Colours and style
- Top bar deep purple (indigo-violet), white text. Page lavender-white.
- Selected month buttons and selected tab: deep purple fill, white text and white tick (months only). Unselected month and tab: light grey.
- Table header lavender with deep purple bold text; body row white with grey outline; text black. No progress bar and no red/amber/green colouring.
- Sub-Channel orange; hierarchy values deep purple bold.
- No packshots.

## Navigation and behaviour
- Per the manual: tap "মেমো টার্গেট" to see the outlet's memo target and achievement for the selected months.
- Month buttons are multi-select toggles (tick appears when selected); the figures cover the selected months only (here Nov + Dec, Oct excluded).
- "এসটিডি টার্গেট" tab returns to the volume table (screenshot 69, right).

## Differences between the image and the manual text
- The manual does not mention the month multi-select with tick marks, nor that October is deselected here.
- The manual does not say the table has a single "All Brand" row with the percent column.
- Labels Sub-Channel, Wing, Division, Territory, Zone, month names and "All Brand" are English in an otherwise Bangla screen.
