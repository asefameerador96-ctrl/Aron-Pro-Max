## tso-slice1 verdict=pass
SUMMARY: TSO slice 1 (bfea7197) passes with no blocking defects, reviewed by reading the lane-only diff from merge-base 951292a48. Changes are confined to TSO code, strings, tests, goldens and docs, with no SR or AMO file touched and no shared core-ui change. Final Submit still submits the same data with the same validation. The main lows are that the inert clear icon announces an action that does not exist, the 'not due' removal does not name the manual rule D-TSO-MAN-51 it overrides, the online map hides staleness cues and Refresh, and the deleted Visit query golden has no ordinary-width replacement. It also carries a 'Clear this route' content description but no button role when onClear is null, so TalkBack announces an action that does not exist. No function is lost, because clear never existed in this build. It is recorded as D-PAR-TSO-03 plus request row 1. A sighted TSO may still tap it and wonder why nothing happens. Consider hiding the semantics label until the host wires the action.

The lane's own status doc says a manual or owner ruling overrides a screenshot (KEEP). D-PAR-TSO-04 does not say it supersedes D-TSO-MAN-51, and the KDoc of FinalSubmitScreen still describes the 'not due' line. The rep now only learns about not-uploaded routes after tapping Submit. Add the supersession note and fix the stale KDoc. FsRoute.notDue is now unused by the UI.

QueryModel.retailer still parses bool criteria from older or other rubrics, so those questions are silently never asked and never answered. Answers are optional per D-199, so nothing blocks. The questions are forced to Bangla (labelBn ?: labelEn) even in English mode, as screenshot 37 shows. This is recorded, but it is a small data-collection reduction.

No ordinary-width Visit query golden remains, and the Final Submit screenshot tests now use the cascade only (loadCascade, pickLevel), so the flat-zone path has no golden (code tests still cover it). Retailer loses its refresh button, count caption and the 'computed on phone' / 'cached' banners (D-PAR-TSO-07). My Team keeps its cached banner. This is recorded and follows screenshots 28 and 29, but it reduces staleness honesty.
