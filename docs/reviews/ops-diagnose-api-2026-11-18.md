### BLOCKING upheld=3/3: The API console query silently drops the API's own database ERROR lines, so the new section can show "no errors" while the API is failing

WHY: The API logs one JSON object per line (backend/app/src/main/resources/logback.xml, logback JsonEncoder) and the stack trace is a field of that same object.
