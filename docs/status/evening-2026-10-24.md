- 13:10 android-print #4 (Opus) found the root cause: `PrintTemplate.TOKEN` ended in a bare `}` that Android's ICU regex engine rejects (U_REGEX_RULE_SYNTAX) while the desktop JVM accepts it, so every memo, stock-slip and summary template failed to parse on the phone and every JVM test passed. Fix 72ff0a37 escapes the braces and adds `AndroidRegexBracesTest`, which applies ICU's rule to every regex literal in android/ and shared/; the print guard now logs to CrashLog.
