## Lessons (short)
A failing "Backend app tests" job whose MCP log tail shows only Postgres noise: fetch the full job log (see backlog: unauthenticated curl on the public repo), then grep FAILED / "tests completed". A seed-topology change (routes, outlets, assignments) always needs the DataFlowTrace hop expectations updated in the same branch — the trace is a contract on the dev seed, and known-findings is for accepted residuals, never for a moved expectation (train 72 candidate, 08:16 UTC 2026-11-04).
A new cfg key needs four things or the Shared/db/backend job fails in SpecCrossCheckTest: the V01xx INSERT, the docs/19 row, the docs/24 §9.5 registry row and the SchemaV1aTest ruled-keys list (train 71's gate caught the missing §9.5 row). Record-writing mechanics: always `cat >> file <<'EOF'` (quoted) when the text may contain backticks or `$`; put long replacement lines in a scratch file and splice them with Python rather than f-strings with quotes; capture `T=$(date -u +%H:%M)` at the start of the write. A new tools/ci/*.py or *.sh must be committed 100755 (infra/validate.sh mode loop); lanes run that loop before pushing (cost today: one cancelled 46-minute gate run).
