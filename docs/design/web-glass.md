# Web glass spec: Calm Glass for the dashboard and admin portal (v1 draft, 2026-10-07)

Binding inputs: `docs/32` (direction, tiers, token names), `docs/31` s1 (gates), `CLAUDE.md`. Sister files: `docs/design/tokens.md` (v1 values) and the Android glass spec. **Where a value here differs from `tokens.md` v1, `tokens.md` wins and this file is corrected.** Rows marked *(web)* are extensions that `tokens.md` should adopt or reject.

Computed, not eyeballed: every contrast ratio in s2.4 was calculated against the worst-case backdrop; the categorical, ordinal and status colours of s10 were run through the dataviz validator (`validate_palette.js`) on the real chart surfaces. Repo today: Next 16, React 19, Tailwind 4.3 (CSS-first: `@import "tailwindcss"` plus `@theme`), Noto Sans Bengali Variable bundled, `components/shell.tsx`, `components/map-panel.tsx`, `components/admin/kit/*`, config pages under `app/admin/config/*`. **No new runtime dependency is needed**; charts are inline SVG.

## 1. Stance for the web (what differs from the phones)

1. **Blur only where something passes behind.** Over the static page gradient a backdrop blur is invisible, so plain cards are translucent tint, sheen and hairline with no `backdrop-filter`. Real blur is spent on the top bar, sidebar, stuck table header, popovers, sheets, dialogs and the map panel (s3).
2. **Data sits on near-opaque glass.** Tables and charts use `surface.data` (92 percent), not 62 percent, so contrast never depends on what is behind.
3. **Desktop first, usable at 360.** Design target 1366 x 768 (the common office laptop) and 1920 x 1080; every page must also work at 360 x 800 for an AMO on a phone.
4. **Density is a user setting** (s8.2). 8,500-user tables need it.
5. **Offline on the web is a calm chip, not a queue.** Admin writes need the server: while offline the page stays readable (data as of HH:MM), write controls are `aria-disabled` with the reason. Never a blocking modal.
6. **Same words as the phones.** Gross, offer discount, DRP discount, QC deduction and net payable keep one Bangla label each (UI-SR-07). Strings live in the i18n layer; examples below are illustrations.

## 3. Glass tiers on the web (the performance contract of docs/32 s2)
| | **A full** (default on desktop browsers) | **B lite** | **C off (solid)** |
|---|---|---|---|
| Selected when | `data-glass="full"` | low-end laptop (`deviceMemory <= 2` or `hardwareConcurrency <= 2`), frame probe fails (p95 over 32 ms across 30 frames after load), user or admin `lite` | `cfg.app.ui_glass=off`, user setting, `prefers-reduced-transparency`, `prefers-contrast: more`, `forced-colors`, no `backdrop-filter` support |
| Cards (`glass-card`) | fill .62 / .12, sheen, hairline, `--elev-1`, **no blur** | same, sheen x1.5 | solid, no sheen |
| Data cards, tables, chart cards | `surface-data` | same | solid |
| Top bar, sidebar | `glass-strong` + `blur(24px) saturate(1.6)` | `glass-lite`, no blur | solid |
| Stuck table header | `glass-strong` + `blur(16px) saturate(1.4)` | lite | solid |
| Popovers, menus, tooltips | `glass-strong` + `blur(20px) saturate(1.5)` | lite | solid |
| Sheets, dialogs | `glass-strong` + `blur(32px) saturate(1.7)` (the only strong blur) | lite | solid |
| Map side panel | `glass-strong` + `blur(24px) saturate(1.6)` | lite | solid |
| Page background | gradient | gradient | gradient; flat `--page-base` under contrast-more and forced-colors |
`cfg.app.ui_glass` (`auto`, `lite`, `off`) comes from the public config at login and wins over `auto`; a user may only choose more solid than the admin allows. A tier is chosen by `pickGlass()` (reduced-transparency, contrast-more or forced-colors always give `off`), cached in `localStorage` `aron.glass`.

```css

  --bf-nav: blur(24px) saturate(1.6); --bf-sheet: blur(32px) saturate(1.7); --bf-pop: blur(20px) saturate(1.5);
  --bf-head: blur(16px) saturate(1.4); --bf-panel: blur(24px) saturate(1.6); --bf-media: blur(12px); }
:root[data-glass="lite"] { --glass-fill-strong: var(--surface-glass-lite); --sheen-k: 1.5; --bf-nav: none; --bf-sheet: none;
  --bf-pop: none; --bf-head: none; --bf-panel: none; --bf-media: none; }
:root[data-glass="off"] { --glass-fill: var(--surface-solid); --glass-fill-strong: var(--surface-solid); --sheen-k: 0;
  --bf-nav: none; --bf-sheet: none; --bf-pop: none; --bf-head: none; --bf-panel: none; --bf-media: none; }
@media (prefers-reduced-transparency: reduce), (prefers-contrast: more), (forced-colors: active) { :root { /* same body as off */ } }
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) { :root { /* same body as off */ } }

```
`prefers-reduced-transparency` support is still partial, so it is an enhancement: the user setting, `forced-colors` and `prefers-contrast` are the dependable paths. Accessibility settings always beat a forced `full`.

`--sheen` is `linear-gradient(180deg, rgb(255 255 255 / calc(var(--sheen-a) * var(--sheen-k))), rgb(255 255 255 / 0) 42%)`.

### 3.1 Blur budget (docs/32: radius and layer count capped)
- Radius at most 32px; never animate the radius; animate `transform` and `opacity` only.
- At rest at most **3** blurred elements in the viewport (sidebar, top bar, stuck table header). An open sheet or dialog sets `data-overlay` on `<html>`, which switches the three under the scrim off, so at most 1 blur pass runs. Cards, rows, chips and chart plates never blur. `glass-over-media` is for a card over the map, an image or scrolling content only.
- If a 320 ms sheet entry drops frames on the reference laptop, enter with the lite fill and switch the blur on at `transitionend`.
- Optional "animated highlight" of tier A: a pointer-following specular on the hero card only (one at a time, `::before` radial gradient moved by `opacity`/CSS variables from a rAF-throttled `pointermove`), `@media (hover:hover) and (pointer:fine)`, off in B, C and reduced motion.

## 4. Typography and numbers (Bangla first)
`--font-sans` puts the system UI face first (SF on Apple, Segoe on Windows, Roboto) for Latin; Bengali glyphs fall through to the bundled Noto Sans Bengali Variable. `:lang(bn)` flips the order (Noto first) so a Bangla page is typographically Bangla, digits included. Weights 400, 500, 600, 700; no light weights (sunlight and cheap screens). No negative letter-spacing anywhere; `:lang(bn) { letter-spacing: 0 }`.
| Utility | Size / line (Bangla line) | Weight | Use |
|---|---|---|---|
| `text-display-xl` | 48 / 52 | 700 | hero figure, **one per view** |
| `text-display` | 34 / 40 | 700 | big numbers, page title (large title) |
| `text-title` | 22 / 30 | 650 | card title, sheet title |
| `text-heading` | 18 / 26 | 600 | section and panel headings |
| `text-body` | 16 / 24 (26) | 400 | forms, prose |
| `text-table` | 14 / 20 (22) | 400 | table cells (density changes it, s8.2) |
| `text-caption` | 13 / 18 (20) | 500 | helper text, chips, axis labels |
`@theme`: `--text-display: 2.125rem; --text-display--line-height: 2.5rem;` and so on. Hero and stat values use proportional figures; `tabular-nums` only in table columns, axis ticks and money columns. Never clip: Bangla text containers have `min-height` from the line height, not a fixed height.
- Numbers go through one formatter (`formatNumber`, `formatMoney` in `lib/i18n`): ASCII stored, Bengali digits per `cfg.locale.digits` (UI-SR-08), money from integer milli-taka with two decimals and a trailing `৳` (`৪,৩৯১.০০ ৳`), quantities with their own unit (sticks, pieces, dozens) beside the value, never summed across units (UI-SR-10). Digit grouping (western `4,391` or lakh `১২,৩৪,৫৬৭`) follows the printed memo: open question Q1.
- Mixed text carries `lang` on the fragment (`<span lang="en">`) so screen readers switch voice.

## 6. Glass navigation
- **Sidebar** (`glass-nav`, 264, border-inline-end hairline): brand row 56; group labels `text-caption` uppercase-free, `fg-3`; items 40 tall, radius 12, icon 20 plus label; active item = `accent-wash` pill, `accent-ink` icon and label at weight 600, `aria-current="page"`; hover `fg` at 6 percent wash. - **Top bar** (`glass-nav`, 56, sticky): scope badge (read-only, server-derived: never an editor of reach), command search (`Ctrl/Cmd+K`: pages, config keys, outlets by id), the sync chip (s12.5), language (`বাংলা | EN`), theme (system, light, dark), density, user menu. Shadow `--elev-2` appears only after the page has scrolled 8 px (`data-scrolled` from the sentinel).
- **Drawer** (below md): `glass-sheet` from the start edge, 320 / 86vw, scrim, focus trap, `Esc` closes.
- **Segmented control** (tabs, density, theme): height 36, radius 12, thumb radius 9 in `surface-solid` with `--elev-1`, the thumb slides with `transform` in 220 ms; roving tabindex, arrow keys, `role="tablist"` or `radiogroup` as appropriate.

Required fields: the word "required" in the label (not a lone red star); optional ones are not marked. Reason fields (every write sends a reason, 10 characters minimum per the config registry) show a live counter ("৭/১০"). **States:**
| State | Treatment |
