# Delta: the owner's AMO manual (October 2026, 77 screenshots) versus the AMO app on INT 756cc24c

Date: 2026-11-06 (lead). Sources: `docs/evidence/manuals/manual-amo-2026-10.md` (sanitised text), `docs/ui-reference/amo/` (77 screenshots + one note each), the capability map of the current app (lead surveyor, read-only, file:line cites kept in the build contract), `docs/07-amo-app.md`, `docs/status/android-amo.md`, `docs/status/ui-parity-ui-amo.md`, `docs/requests/android-amo-*.md`, the earlier `delta-amo.md` (2026-10-04, 62-screen vendor manual 1.0.2).

What changed since the October build: the AMO app was built from the 62-screen manual **without screenshots** (PARITY-SPEC: "layout from manual, needs owner screenshot") in the SR visual language, with an 8-hub Home (D-AMO-HOME-01). The owner's new manual gives the **vendor AMO look screen for screen** (solid deep-purple top bar, light page, white cards, 3-column tile grid with gradient icons, blue/green/red buttons) and adds or changes behaviour (force-sale reason, previous sale data by date, Sales Journey, Team Location and Update Base on a real map, Team Performance cards with brand detail, Home target cards, date pickers, success dialogs). Under owner directive 14a the screenshot wins; the standing rules that the screenshots do not override are listed in `docs/ui-reference/amo/README.md`.

## Headline
- 77 screenshots: **19 are already matched end to end** by the current app apart from look and wording; **39 need look and wording parity on an existing screen** (same data, different layout, Bangla strings, dialogs); **13 need new behaviour or new server data** (G-AMO-11-01…13 below); **6 are deferred by the sponsor** (Astha 67–70 and the Astha-based route-info/shop-wise reports; the Campaign Enrollment tile of screenshot 8); the remaining rows are Android system or installer dialogs proven by name/version tests and the device walk.
- One cross-layer fault found by the survey: the server refuses the AMO role on `GET /v1/dashboards/login-submit` (DASHBOARD_ROLES excludes AMO), so the current Live Dashboard screen can only show "Gone" on a phone. Fixed in the foundation train (B1).
- The AMO app has never run on a phone (every acceptance DEVICE-PENDING). The build contract ends with a signed AMO APK and a 77-row device walk for the owner.
